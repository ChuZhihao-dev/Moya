# 页面 SEO 条款

来源 B 的四张表。下面按原表逐项整理；具体原文位置由章节及条目名定位。Schema 的运营配置（Section Schema）与 SEO JSON-LD 是两种不同概念。

## 一、首页

| 编号 | 原表条目 | 级别 | UI / 开发要求 |
|---|---|---|---|
| HOME-01 | H1唯一 | 必须 | 仅一个 H1，包含核心关键词；通常放在 Banner 主标题，不在品牌 ICON/LOGO 重复设置 H1 |
| HOME-02 | H2-H3结构清晰 | 建议/原则 | 模块 H2、子模块 H3，按内容层级组织，不为样式滥用 Heading |
| HOME-03 | 首页需有可抓取文本 | 必须 | 不能只有图片/视频；Banner 图文分离，核心文案用真实 HTML |
| HOME-04 | 首页需有Schema结构化数据 | 必须/推荐类型 | 支持主页结构化数据，建议 Organization / WebSite |
| HOME-05 | 首页需有核心分类入口 | 必须 | 设计核心分类入口模块，并以可抓取链接连接核心集合页 |
| HOME-06 | Banner避免纯视觉化 | 必须 | Banner 文字不做进图片，图文分离 |

## 二、集合页

| 编号 | 原表条目 | 级别 | UI / 开发要求 |
|---|---|---|---|
| COL-01 | 集合页需独立Title / H1 | 必须 | 每页独立 SEO 主题，页面顶部预留 SEO 标题区域 |
| COL-02 | H1唯一 | 必须 | 仅一个 H1，通常为当前分类名 |
| COL-03 | H2-H3结构清晰 | 建议/原则 | 页面主题→内容模块→子内容，不为样式滥用 Heading |
| COL-04 | 集合页需SEO文案 | 必须 | 产品列表上方预留并支持真实文本模块，图文分离 |
| COL-05 | 支持FAQ模块 | 必须支持 | 页面底部预留 FAQ 区域 |
| COL-06 | FAQ需支持FAQ Schema | 条件适用 | 有 FAQ 内容时模块输出对应结构化数据 |
| COL-07 | 支持面包屑导航 | 必须 | 页面顶部展示面包屑 |
| COL-08 | 面包屑需支持Breadcrumb Schema | 必须 | 输出与路径一致的 Breadcrumb 结构化数据 |
| COL-09 | 支持分页规范化 | 必须 | 后续分页内容可抓取，不只用无 URL 的无限加载 |
| COL-10 | 支持内链模块（可选） | 可选 | 推荐相关分类/博客 |
| COL-11 | URL结构规范 | 必须 | 简洁、包含关键词，避免过长动态参数 |

仅建议布局：H1 标题 → SEO 描述文案 → 筛选器 → 产品列表 → 分页 → FAQ → 相关文章推荐。不要把顺序或可选模块变成强制设计。

## 三、产品页

| 编号 | 原表条目 | 级别 | UI / 开发要求 |
|---|---|---|---|
| PDP-01 | 产品标题为H1标签 | 必须 | 产品标题为唯一 H1，位置不可隐藏 |
| PDP-02 | 产品描述需可编辑 | 必须 | 描述可编辑，避免只用图片介绍 |
| PDP-03 | H2-H3结构清晰 | 建议/原则 | 模块 H2、子模块 H3，不为样式滥用 Heading |
| PDP-04 | Product Schema | 必须 | 输出 Product 结构化数据，联同 DEV-19 检查 |
| PDP-05 | Review Schema | 条件适用 | 有用户评价模块时支持 Review Schema，与真实评价对应 |
| PDP-06 | Review评分模块（可选） | 可选 | 支持 UGC；无需因此强制增加评价模块或 App |
| PDP-07 | FAQ Schema | 条件适用 | FAQ 模块输出对应 Schema |
| PDP-08 | FAQ模块 | 必须支持 | 页面底部预留 FAQ 区域 |
| PDP-09 | Breadcrumb Schema | 必须 | 面包屑导航输出 Breadcrumb Schema |

仅建议布局：产品标题 H1 → 产品图片 → 核心卖点 → 产品描述 → 参数信息 → 用户评价 → FAQ → 相关推荐。评价数据、模块存在与否需按项目判断。

## 四、其他 Page（如 FAQ、About Us）

| 编号 | 原表条目 | 级别 | UI / 开发要求 |
|---|---|---|---|
| PAGE-01 | 页面仅允许一个H1 | 必须 | 主标题用 H1，避免多个或隐藏 H1 |
| PAGE-02 | H2-H3结构清晰 | 原则 | 模块标题层级清晰，不为样式滥用 Heading |
| PAGE-03 | 页面需有可抓取文本内容 | 必须 | 图文分离，核心内容为 HTML 文本，避免纯图片 |
| PAGE-04 | 页面需支持内部链接 | 必须支持 | 设计相关推荐/相关页面模块，加强内部链接 |
| PAGE-05 | 页面需支持面包屑导航 | 必须支持 | 顶部预留面包屑，输出 Breadcrumb Schema |
| PAGE-06 | 页面需支持FAQ模块（仅FAQ页面） | 条件适用 | FAQ 页面底部预留 FAQ 区域，FAQ 支持对应 Schema；不扩展为所有 Page 强制 FAQ |
| PAGE-07 | 页面需支持结构化数据 | 必须 | 根据页面类型输出对应 Schema |
| PAGE-08 | URL需简洁规范 | 必须 | 与页面主题一致，避免动态参数、中文、特殊符号；已有 URL 调整边界见来源说明 |

## 验证提示

UI 检查预留区域、文字与图片分离、层级和可编辑能力；开发检查最终 HTML、实际链接、分页 URL 和 JSON-LD；内容人员尚未提供文案、FAQ 或真实评价时，区分“能力已实现”和“上线内容已验收”，后者应待验证。
