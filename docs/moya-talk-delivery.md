# Talk to MoYa：配置与交付记录

日期：2026-10-23。组件已接入开发主题首页，位于第一组 Meet Moya 之前；未发布线上主题。

## 配置与运行

- Theme Editor 添加 **Moya Talk**。Section 提供标题、状态标签、颜色、开场滚动距离、文字速度、选项延迟、动画开关，以及桌面／手机人物尺寸、位置、海报和六组动作视频。
- 默认使用已迁入主题的参考站素材，无参考站运行时请求。可用 Shopify 视频选择器逐项替换；手机未设置自定义视频时，继承相应自定义桌面视频。默认内置素材有两套分辨率。
- 开场 MP4 应从近景连续拉远到待机姿态。动作视频必须与待机视频保持构图、背景、起止姿态一致；hug 配 return，look-up 配 look-down。使用静音 MP4。
- 每个 **Dialogue node** 有唯一 ID、跟进问题和两个选项。每个选项可配置回复、动作、下一节点 ID，或选择重新开始／链接。起始节点默认为 `opening`。
- 默认完整路径为 `opening → conversation / quiet → closing`，两轮共四条路径；对应参考站原始选项、反馈和跟进问题。
- 回复先逐步显现；普通动作结束停留 0.75 秒，拥抱结束停留 1.5 秒，再通过返回片段进入待机；随后显示目标节点的跟进问题和下一轮选项。停留期间离屏／切后台会暂停计时；失败降级或减少动态效果时跳过姿态停留。`Reply reveal starts/ends` 是回复视频时间点，结束值 0 表示视频结尾。
- `#moya-science` 是默认探索目标的便捷值，运行时解析为当前页面 Science Section 的真实 ID；其他目标保留配置中的真实 href。
- 节点 ID 重复／缺失、无效目标、直接自循环、不安全链接和不可达节点在编辑器内显示提示；不渲染无效选项。删除节点后需同步修改引用。
- 默认允许正常页面滚动，不锁滚轮。开场占用一个可用视口高度，之后额外保留 60% 视口的选择区间；向上回退隐藏互动并暂停，回来恢复原轮次。刷新页面回到初始分支，不写入浏览器存储。

## 构建与测试

```sh
npm run build:talk
npm run test:talk
node --check assets/moya-talk.min.js
shopify theme check --output json
```

构建依赖固定版本 esbuild；优先项目依赖，当前工作区也可使用已安装 Shopify CLI 自带的同版本 esbuild。实际页面只引用 `.min.js` / `.min.css`。修改源 JS/CSS 后必须重新构建。

截图证据：`/private/tmp/moya-talk-desktop-proof.jpg`。手机视口截图导出存在缩略图问题，手机布局以实际界面观察和 DOM 几何记录为证，不使用该缩略图作为视觉验收证据。

测试使用 Node 内置测试运行器与模拟 DOM、视频、可见性和时钟，覆盖交互逻辑，不替代真实浏览器排版／媒体解码测试。当前 12 项测试通过：四条完整分支及重启、重复点击、懒加载范围、后台暂停、反向滚动暂停恢复、设备媒体切换、减少动态效果、媒体错误、无效配置和卸载清理。

## 响应式与媒体策略

- ≥1200px：桌面三列构图；750–1199px：紧凑三列；≤749px：按手机设计稿排布 Listening 与选项，回答上方、问题右下。
- 使用稳定的小视口高度探针处理移动浏览器地址栏变化；可用高度不足 545px（手机）／560px（桌面）或文字发生碰撞时，改为自然文档排布。
- 两个选项默认均为半透明浅色，仅鼠标悬浮时呈淡绿色。状态点保持在 Listening 和回答期间可见，五点从左向右依次呼吸，遵循减少动态效果设置。
- 按设计保留手机选项 10px 字号，可见框体最小高度 35px、间距 10.93px；通过伪元素扩展至至少 44px 点击高度。编辑为较长选项时允许换行、增高。
- 六类动作生成桌面 1920×960、手机 1280×640 两套 H.264 MP4，移除音轨并启用 faststart；开场 GOP 为 3 帧，其他 30 帧。
- 临近视口才加载开场，Listening 阶段仅额外准备当前选项可能使用的动作；Data Saver 模式不预备分支视频。离屏／后台暂停。
- 视频准备失败或超时 8 秒，使用海报与文字时钟继续对话；不会因视频失败锁住选项。媒体切换始终有有效海报兜底。
- Figma 原始头像与 SVG 存在主题内；头像使用 Shopify `asset_img_url: '256x'`，近景海报使用 `2400x`，避免直接传输大尺寸原图。
